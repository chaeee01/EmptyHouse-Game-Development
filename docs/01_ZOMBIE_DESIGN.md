# 01. 신규 좀비 기획 — 선생님(Teacher) · 학생(Student)

# A. 선생님(Teacher)

> 상태: 기획 확정 · 구현 완료 · 플레이 테스트 1차 완료(일부 미확인 — 04 참고) (2026-11-23 기준)
> 외형: **미제작** — 기존 Walker 모델·애니메이션을 임시로 사용한다. 콘셉트 이미지만 있다.

## 1. 콘셉트
- 복도에서 뛰는 학생을 잡아 세우는 선생님. **시야 안에서 달리는 플레이어에게만** 반응한다.
- 플레이어 경험 목표: "뛰면 걸린다"는 긴장 — 도주(달리기)라는 기본 생존 수단에 비용을 붙인다.

## 2. 행동 규칙
| # | 상황 | 반응 |
|---|---|---|
| 1 | 시야 안에서 걷기·웅크림·정지 | 무반응 (근접해도 반응하지 않음) |
| 2 | 시야 안에서 달리기 | 즉시 **경고** — 제자리에서 경고 연출, 경고 타이머 시작 |
| 3 | 경고 중 달리기 중단 (유예 0.25초) | 경고 취소 → 타겟·위협 해제 → 순찰 복귀 |
| 4 | 경고 중 시야 상실 (유예 0.75초) | 경고 취소 → 순찰 복귀 |
| 5 | 경고를 무시하고 2초간 계속 달림 | **추격** |
| 6 | 추격 중 걷기로 전환 | 즉시 해제하지 않음 — 기존 추격 규칙(시야 상실 → 관성 추격 → 조사 → 귀가)을 따른다 |
| 7 | 소리 | 듣지 않는다 (청각 채널 꺼짐) |
| 8 | 다른 좀비와 무리 동조 | 하지 않는다 |

## 3. 수치 (임시값 — 플레이 테스트로 조정 예정)
| 항목 | 값 | 비고 |
|---|---|---|
| 경고 시간 | 2.0초 | 이 시간 동안 계속 달리면 추격 |
| 달리기 중단 유예 | 0.25초 | 달리기 키 순간 떼기·네트워크 복제 지연 흡수 |
| 시야 상실 유예 | 0.75초 | 기둥·문틀에 잠깐 가린 경우 흡수 |
| 시야각 / 거리 | 80° / 10m | Walker 값에서 출발 |
| 추격 속도 | 4 m/s | Walker 값 (플레이어 달리기 5 m/s) |

## 4. 설계 판단
- **Walker Prefab Variant가 아니라 독립 종으로 만든 이유**: 종 식별은 프로파일 파생 타입, 고유 행동은 컨트롤러 파생 훅이 정하는 구조다. Variant는 Walker 종으로 남아 Walker 무리에 묶이고(무리원은 대표 상태를 복사), 고유 규칙을 넣을 자리가 없다.
- **경고를 새 상태 종류가 아니라 기존 "발각 전환" 단계의 교체로 구현**: 네트워크로 복제되는 상태 종류를 늘리지 않아 클라이언트의 포효 애니메이션·음성 연출을 그대로 재사용한다(기존 Oiler의 '놀람' 상태와 같은 방식).
- **다인 플레이 한계(인지)**: 시야 판정은 원뿔 안 최근접 1명만 대상으로 한다. 가까운 플레이어가 걷고 먼 플레이어가 달리면 감지하지 못한다.
- **추격 이후는 기존 규칙 유지(플레이 테스트 후 확정, 2026-11-23)**: 추격이 시작되면 걸어도 풀어 주지 않는다. 시야를 잃어도 관성 추격 8초 안에 다시 보이면 걷고 있어도 추격을 재개한다. "경고를 무시한 대가"를 분명히 하기 위한 선택이다.
- **경고 연출 가시성(미해결)**: 경고는 상체 포효 클립을 재사용해 정지 + 포효로 표현한다. 1차 플레이 테스트에서 잘 보이지 않는다는 관찰이 있어 재확인 예정. 경고 시간(2초)과 전용 애니메이션 제작은 이번 범위에서 제외.


## 5. 상태 전이와 취소 조건 (코드 기준)
경고는 새 상태 종류를 만들지 않고 기존 발각 전환(`RoarTransition`) 자리를 `TeacherWarningState`([코드](../src/Teacher/TeacherStates.cs)) 로 교체해 구현했다. 판정은 `TeacherWarningRules.Step`([코드](../src/Teacher/TeacherWarningRules.cs)) 이 매 서버 틱 수행한다.

| 현재 상태 | 조건 | 다음 상태 | 처리 |
|---|---|---|---|
| 배회·경계·조사·진정 | 시야 안 대상이 걷기·정지·웅크림 | (유지) | 감지 게이트가 시각 자극·근접 반응을 지움 — 의심도 오르지 않음 |
| 배회·경계·조사·진정 | 시야 안 대상이 **달리는 중** | 경고(`RoarTransition`) | 의심도 바닥 100 + 타겟 확보 → 코어가 발각 전환 |
| 경고 | 달리기 중단이 **0.25초** 이상 연속 | 배회 | `CancelSprintStopped` → `ServerCalmDown`(타겟·래치·의심도 해제) |
| 경고 | 타겟 본인을 못 본 시간이 **0.75초** 이상 연속 | 배회 | `CancelLostSight` → 위와 같음 |
| 경고 | 타겟 소실(사망·귀환·위장 등) | 배회 | `CancelNoTarget` → 위와 같음 |
| 경고 | 경과 **2초** (위 취소 조건이 같은 틱에 겹치면 취소 우선) | 추격(`Chase`) | 기존 추격 규칙으로 인계 |
| 추격·관성 추격·공격 | — | (팀 기존 규칙) | 감지 게이트 미적용 — 걸어도 즉시 해제되지 않고, 시야 상실 시 관성 추격 8초 안 재발견하면 추격 재개 |
- 경고 → 배회 전이 시 클라이언트는 상체 포효를 0.15초 크로스페이드로 끊는다(경고 → 추격은 종전대로 이어 재생).

# B. 학생(Student)

> 상태: 기획 확정 · 구현 완료 · 자동 테스트 완료 · 플레이 테스트 1차 완료(일부 미검증 — 04 5절) (2026-11-23 기준)
> 외형: **미제작** — 기존 Walker 모델·애니메이션 임시 사용. 비명 전용 음성도 없음(예고 시작 시 기존 포효 음성 재사용).

## 1. 콘셉트
- 교실 주변을 배회하다 플레이어를 보면 **비명을 질러 주변 좀비를 불러 모으고 달아나는** 학생. 직접 공격하지 않는 대신 상황을 악화시킨다.
- 플레이어 경험 목표: "들키면 시끄러워진다" — 예고 중 시야를 끊거나 기절시키면 비명을 막을 수 있는 **대응 창**을 준다.

## 2. 행동 규칙
| # | 상황 | 반응 |
|---|---|---|
| 1 | 평소 | 교실(스폰 지점) 주변 배회 |
| 2 | 시야로 플레이어 발견 | 즉시 **비명 예고** — 제자리 정지 + 예고 연출 |
| 3 | 예고 중 시야 상실(0.25초 유예) | 비명 취소 → 배회 복귀 |
| 4 | 예고 중 경직·기절 | 비명 취소 |
| 5 | 예고 1.5초 완료 | 서버가 **비명 소음 이벤트 1회** 발행 → 주변 좀비가 기존 청각으로 그 위치를 조사 |
| 6 | 비명 직후 | 플레이어 반대 방향으로 **도주** → 3초간 못 보면 진정 → 귀가 |
| 7 | 쿨다운(20초) 중 다시 발견 | 비명 없이 바로 도주 |
| 8 | 소리 | 듣지 않는다(자기 비명에 반응하지 않게 청각 끔) |
| 9 | 무리 동조 | 하지 않는다 |

## 3. 수치 (임시값 — 플레이 테스트로 조정 예정)
| 항목 | 값 | 비고 |
|---|---|---|
| 비명 예고 | 1.5초 | |
| 예고 중 시야 상실 유예 | 0.25초 | |
| 비명 크기 | 80dB | 기존 소음 전파(거리당 1.5dB 감쇠, 벽 60dB 차폐) 그대로 — 트인 공간 기준 Walker(가청 30dB)는 약 33m 안에서 조사 반응, 벽 너머는 거의 닿지 않음 |
| 쿨다운 | 20초 | |
| 도주 속도 / 포기 | 3 m/s / 3초 | 플레이어 걷기 3.5 m/s, 달리기 5 m/s |
| 시야각 / 거리 | 80° / 10m | Walker 값에서 출발 |

## 4. 설계 판단
- **소음은 기존 시스템으로만**: 새 "호출" 메시지를 만들지 않고 서버 단발 소음 이벤트를 발행한다. 소음원이 플레이어가 아니므로 듣는 좀비는 타겟을 잡지 않고 위치 조사만 한다 — 기존 소음 규칙과 같은 동작이라 다른 좀비 코드를 바꾸지 않았다.
- **예고를 발각 전환 자리의 교체로 구현**: Teacher 경고와 같은 방식. 예고 취소 시 Teacher 용으로 만든 포효 중단을 그대로 옵트인했다.
- **도주는 Oiler 참고 · 독립 구현**: Oiler 도주 상태는 Oiler 컨트롤러·프로파일 타입에 묶여 있어 재사용 대신 알고리즘만 참고해 독립 구현했다. 후보 방향 생성·점수·포기 판정은 순수 규칙으로 분리해 테스트했다.
- **쿨다운 중 즉시 도주**: 발각 전환을 거치면 예고 연출(포효)이 한 순간 재생되므로, 쿨다운 중에는 상태 머신으로 바로 도주를 건다. 이를 위해 공용 컨트롤러에 상태 머신 접근자 1줄을 추가했다.
- **한계(인지)**: 비명 위치는 학생 자신의 위치다. 벽 차폐로 교실 밖에는 거의 닿지 않는다(문 열림 여부에 좌우) — 플레이 테스트로 크기 조정 예정.

## 5. 상태 전이와 취소 조건 (코드 기준)
예고는 발각 전환(`RoarTransition`) 자리를 `StudentScreamWindupState` 로, 도주는 `Flee` 자리를 `StudentFleeState` 로 교체해 구현했다([코드](../src/Student/StudentStates.cs)). 판정은 `StudentScreamRules`([코드](../src/Student/StudentScreamRules.cs)) 가 수행한다.

| 현재 상태 | 조건 | 다음 상태 | 처리 |
|---|---|---|---|
| 배회·경계·조사·진정 | 시야에 플레이어(쿨다운 아님) | 예고(`RoarTransition`) | 의심도 바닥 100 + 타겟 확보 → 코어가 발각 전환 |
| 배회·경계·조사·진정 | 시야에 플레이어 + **쿨다운 중** | 도주(`Flee`) | 발각 전환을 거치지 않고 상태 머신으로 즉시 전이(예고 연출 없음) |
| 예고 | 타겟 본인을 못 본 시간이 **0.25초** 이상 | 배회 | `CancelLostSight` → `ServerCalmDown`, 비명 없음 |
| 예고 | 타겟 소실 | 배회 | `CancelNoTarget` → 위와 같음 |
| 예고 | 경직·기절 | (코어 처리) | 전투 중단 동안 예고 Tick 이 돌지 않고 회복 시 다른 상태로 전이 → 비명 없음. 규칙에도 `CancelIncapacitated` 로 명시 |
| 예고 | 경과 **1.5초** | 도주 | `ServerEmitScream` 으로 서버 소음 이벤트 **1회** 발행 + 쿨다운 시작. 한 예고에서 비명은 다시 반환되지 않음(`Screamed` 플래그) |
| 도주 | 위협 반대 방향 지점으로 이동, 1초마다 재선정 | (유지) | 후보 8방향 중 위협 쪽(정렬 < -0.2) 제외 → NavMesh 스냅 → 거리+정렬 점수 최고점 |
| 도주 | 타겟을 **3초** 이상 못 봄 | 진정(`Subside`) → 배회 | `ServerForgetThreat` → 귀가 후 배회 |
- 예고 → 배회(취소) 전이 시 상체 포효를 즉시 끊는다(Teacher 와 같은 옵트인). 예고 → 도주는 이어 재생.
